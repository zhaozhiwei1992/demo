window.open（后端必须给文件名）
后端必须正确设置 Content-Disposition header，否则浏览器拿不到文件名会显示 undefined。

Blob 下载（推荐，后端不需要管文件名）
1. 前端 fetch 请求，responseType: 'blob'
2. 拿到 blob 后创建 object URL
3. 用 <a download="任意文件名"> 触发下载
4. 文件名完全由前端决定，后端只管吐流

axios + blob 下载
和 fetch+blob 同理，只是换用 axios 发请求。
